# Prebuilt portable packages

Generated by `../tools/build-release-packages.sh`.

These archives are checked in so players can download them from the repo
when a GitHub Release upload is unavailable. Prefer attaching the same
files to a published GitHub Release after merge.

|------|----------|
| CRT-Spaceship-Windows-x64.zip | Windows |
| CRT-Spaceship-macOS-universal.tar.gz | macOS |
| CRT-Spaceship-Linux-x64.tar.gz | Linux |
| CRT-Spaceship-Web.zip | Universal web |
| CRT-Spaceship-Android-Web.zip | Android (web) |
| CRT-Spaceship-iOS-Web.zip | iOS (web) |
| SHA256SUMS.txt | Checksums |
